# 关于名字、细节与插图

## 一、书里的人

两本书写的是真实存在过的人：伞铺的老师傅、缝纫机的阿珍、送奶的老蒋、夜班车上的范师傅、
早餐摊的老郭与阿琴、修表的老许、打印店的小吕、收废品的老黄，还有香积寺路、拱宸桥、小河
直街、笕桥、北门转角那几个地方。

他们的名字在书里是借来的。卷五《借来的名字》与卷六里出现的人名全部是化名，真名记在一个
牛皮封面的本子上，那个本子不出版，也不进这个仓库。

除了名字，还动过这些：铺子的具体位置、门牌、进货价与工钱、生病与受伤的时间、家里人的
称谓。价钱改得最多，因为价钱最容易被认出来。事情本身没有改：谁在等什么、谁算了多少钱、
谁手上有一处伤，这些是真的。

他们知道并且同意：老金说过一句“你把我写成可怜的，我就不认”；阿珍看过稿，说“这是写的
我”；老黄不肯看稿，只交代了一句“你别把猫写没了”，猫在书里留着。

如果其中任何一位，或者读到某一段认出是自己的人，希望删掉、改名或改细节，说一声就改，
不必解释理由。仓库上有 Issue，也可以走邮件。

## 二、叙述者

“我”（林深）是这本书的叙述声音。写作口径上他是一个人：在杭州做产品与技术，一九九一年
生，家里有常山的父母。但书里的日期、对话、账目是文学处理过的，不能当履历读。第一本书的
扉页上印的是“私人印本”，第二本也是；两本书都没有发行、没有定价、没有卖过一本。

## 三、插图

封面一张，每卷一张，共十四张（两本各七张），放在 `books/*/assets/images/`。

流程是：先用文字描述场景（纸色的桌面、清晨的窗、信纸与旧信封、修表台上散开的零件），由
图像模型生成，再做三件事，按书的开本裁切、统一调色（把饱和度压下来，让六张看起来像同
一卷胶卷洗出来的）、检查手部和文字类细节（模型画的手和招牌字经常有问题，改不了的就换一
张重生成）。

所以插图不是照片，不指涉任何真实门牌、真实店面或真实的人脸。它们的功能是给卷首留一块
安静的地方，像旧书前面那一页画。
