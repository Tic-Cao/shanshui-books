## 二、续本写作过程中改掉的实质问题

按卷顺序记，都是通读时抓出来的，不是机器抓的：

1. **四篇不够长**。卷一《旧地址》等四篇曾低于四千，补的是场景与对话：老许那只没人领的钟、
   阿珍抽屉上裂了一道缝的玻璃、母亲记账本上跟在一笔钱后面的那句当天的事。没有靠加长
   感想凑数。
2. **《旧地址》里那句“愿你写下去”**。汪老师不会这么说话，改成“接着写”。
3. **顾青的年龄**。初稿卷一写她三十六、三十七，卷六又写她三十四。定成二〇二六年十二月
   三十三岁、二〇二七年三十四岁，卷一《第一封回信》改到与卷六一致。
4. **我的年龄**。卷一《邮箱里的草稿》写“我今年三十六岁”，与卷二的三十五岁冲突；按一九九一
   年生，二〇二六年十二月还是三十五。
5. **桂花树的树龄**。卷六《写给四十五岁》写成四十九年，卷三是四十三年；统一四十三年，九年
   以后五十二。
6. **第二本书的排期**。卷六《第二本书》里初稿写“从二〇二七年十一月排到二〇二八年十月”，
   那是书里时间还没走完就排了明年，改成“从二〇二六年十一月排到二〇二七年十月”。
7. **后记的账**。五百本、九千一百五十块（一本十八块三）、寄二十一户两百二十六块（省内八块、
   省外十二块）。初稿这三处对不齐，逐个改过并把“二十一户”补进正文。
8. **重复的句子**。五处同一句话在两行内出现两遍，像手抖：《压在书里的信》的折信段、
   《膝盖》的“你不记得，我记得”、《表停了》的“一百八，能买个新的”、《打印店》的
   “人家拿走以后，跟你没关系”、《冬至》的“顾青在本子上写了一行”。改法各不一样：有的
   删掉一遍，有的让说话的人自己纠正上一句（打印店那处就是他说错了又改口），有的换一个
   动作。
9. **台灯的左右**。卷六《不着急》里先写把台灯挪到左角被手挡光，又写挪回右角、第二天挪到
   左角，物理上说不通。改成：灯照的是墙，换一只二十八瓦的黄灯泡，最后把桌子往窗边移三十
   公分。“你把纸挪到光里，不要把人挪到暗里”，这一句是她说的。
10. **时间顺序**。《冬至》里三处：蓝格子抹布出现在它被裁出来之前；“从桥下回来，七点以前”
    的换灯泡排在七点的视频通话之后；夜里写“刚出锅的汤圆”。分别改成抹布的来历由她自己说出、
    不带具体日期的“那天她在我家换了一只灯泡”、热了一只碗的剩汤圆。
11. **标点**。卷一《读者的字》里引号内跟了一个半角逗号；卷六《写给四十五岁》有三行以上
    空行；两本书里原有的破折号清掉，不再用。

## 三、第一本

第一本沿用同一套检查，做过三轮机械扫描加两轮分卷通读，主要是把早期篇章里偏“总结”的
句子改成具体的事，并把卷五的人物统一改成化名。数字口径没有再动过：208,045 字，六卷
四十八篇，二〇二六年十一月印三百册。

## 四、有意保留的写法

- 卷二《代码审查》《一次上线》《凌晨两点的构建》里的英文与半角符号：`feat:`、`worker`、
  `Ctrl+C`、CSV 表头、那三行 SQL。它们在书里是被读出来的代码，不是作者的句子。
- 临安的地名“於潜”的“於”。
- 引文、招牌、账目里的阿拉伯数字。

## 五、这次没能验到的部分

`dist/` 里两个 HTML 与重建产物逐字节比对过。阅读交互是靠脚本读 DOM 验的，不是靠眼睛：

- 《山水有回信》：五十四篇加序与后记，六卷，五十四个篇章锚点无一断链，目录与抽屉里
  110 个链接可达，七张插图全部解码；夜间模式、三档字号（中档 17px，实测大档 19.5px）、
  抽屉开合、顶栏、进度条 `scaleX`、面包屑随滚动换字，键盘左右跳卷，都逐项跑过。
- 《山水有信》：48 篇、六卷、序与后记、251 个内部锚点 0 断链；正文 17px、首行缩进 34px、
  行距 2.05；封底印着「全书六卷，四十八篇，约 208,045 字」与化名声明。六张卷首图设了
  `loading="lazy"`，在后台标签里不会立刻解码，切到前台或强制解码后全部正常。

没有验到的是观感。当时截图工具不可用（应用内浏览器的视口接口返回不可用），版面好不好看、
字距舒不舒服，只能由打开文件的人自己判断。发现串行、断字、颜色刺眼之类的问题，欢迎开
