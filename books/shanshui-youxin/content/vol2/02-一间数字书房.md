# 一间数字书房

硬盘插进去，咔的一声，屏幕右上角弹出一个白色图标，转了两圈，才显出名字：OLD_500。

这块硬盘是二〇一三年买的，五百个G，外壳的塑料已经发乌，边角有一道裂纹，用透明胶粘过。里面装着大学最后一年到工作头几年的东西。我有四年没打开它了。

三月三十日，星期六，晚上八点十分。窗外在下雨，雨点打在空调外机上，声音不匀。

我要把旧东西收拢。

写作这件事，我从二〇一六年开始，一直散着。早几年发在一个写作平台上，后来平台改了两次版，编辑器越改越花，首页开始推别人的文章。我的东西还在，只是每次打开都要先关掉两个弹窗。去年冬天我起了个念头，想给它们找一个自己的地方。

不是搬家，是盖房子。盖一间不上锁的书房。

旧文二十六篇，我打算全部搬过来。图的链接要一张张换，有的图早就没了，只剩一个裂开的图标。换到第二十篇的时候我停下来，把没有图的段落改成了纯文字，读起来反而顺。

那些旧文里，有几篇的配图在改版之后丢了，剩下一个灰色的框。还有一篇的段落被自动排版拆成两半，中间插进一句推荐语，我一直没去改。东西放在别人家里，写的时候总觉得自己是个租客。

先得把书找齐。

硬盘的根目录下有十七个文件夹。名字分别是：毕业论文、照片、杂、新建文件夹、新建文件夹(2)、backup、backup_final、歌词、电影、工作、工作2、简历、扫描件、手机备份、待整理、临时、aaaa。

我点开“待整理”，里面是空的。点开“新建文件夹(2)”，里面还有一个“新建文件夹”。

“aaaa”是我大四那年建的，用来放一个第二天就要交的作业。建的时候很急，随手敲了四个字母。作业早就交了，文件夹留到现在，里面有三个文件，两个是我做的，一个是从网上下的模板。

这就是问题所在。七八年里，我每次换电脑、重装系统，都是把旧东西整个拷过来，往一个新文件夹里一塞。塞的时候想，以后再说。以后一直没来。

我坐在椅子上看了一会儿这些名字，先关掉了“照片”。

我要找的是一篇旧文。

二〇一六年秋天写的，写二〇一三年七月，我从学校搬出来，住进拱墅区一间一楼的出租房。写了什么我记不全了，只记得一个数字：七摞。我把书码在墙边，码了七摞。

那几年我搬过三次家，书一次比一次多。七摞这个数，大概只有第一间屋子才有。

我在搜索框里输了“租房”，没有。输了“搬家”，出来一堆照片。又输了“2013”，出来的是课程表和一张火车票的扫描件。

文件名是靠不住的。

硬盘转起来有很轻的嗒嗒声，隔一会儿响一下，像有人在隔壁敲墙。

我数了一下，硬盘里的 Word 文档有两百一十七个。大部分没有标题，叫“1”“2”“新建文档”“最终版”“最终版2”。挨个打开，一个晚上也打不完。

于是我给自己的懒惰写了一个脚本。

十八行。从一个目录开始，把所有 .docx 找出来，读出里面的文字，另存成同名的 .txt，放在一个临时文件夹里。用的是一个现成的库，几行就够。

脚本跑了四十秒。屏幕上滚过一串文件名，最后停在一行：转换完成，二百一十七个。

我在那个临时文件夹里搜“七摞”。

出来三个结果。一个是一份课程作业，里面写着“七摞砖”；一个是二〇一八年的购物清单，写着“七摞打印纸”；第三个在一个叫“1.docx”的文件里。

转换出来的文本有些地方是乱的，段落的顺序偶尔颠倒，标点变成问号。我不打算修，能搜就行。

路径是：新建文件夹(2)/新建文件夹/1.docx。

修改时间是二〇一六年十一月三日，晚上十一点二十。

我点开它。

标题叫《第一间屋子》，两千四百字。开头第一句是：“二〇一三年七月，我从学校搬出来，那天下雨。”

我读到中间，看见了自己写的那句：我把书码在墙边，码了七摞，最高的那摞到我膝盖。窗台很低，下雨的时候水会从缝里渗进来，我用一只旧毛巾堵着，毛巾一直是湿的。

后面的句子开始啰嗦。二十四岁的人写东西，喜欢把每一件事都解释一遍。屋子潮，他要解释为什么潮；隔壁吵，他要解释吵的是谁；连自己为什么睡不着，也要写三段。

只有一处我没有改。写停电的那一段，他说点了一根蜡烛，坐在纸箱上，看墙上的水迹。那句是：“关灯以后，墙上的水迹像一张地图，我躺着认了很久，认出了几个省。”

我把这篇文章复制到新文件夹里，路径是 drafts/2016/first-room.md。

在文件开头加了一行：二〇一六年十一月，写二〇一三年七月。原文未改。

然后关掉，没有发。

盖房子的事，拖到了第二天。

星期天下午，我把 Streamlit 装在那台旧笔记本上。选它，是因为我只会写后端的东西，前端一行也写不利索。它能把 Python 直接变成页面，样式不多，但够用。

第一件事是起名字。

我有一个文本文件，叫 names.txt，里面存着这些年想过的名字：沿运河、慢船、雨天备忘记、拐弯、山止川行。最后一个是我二〇一九年加进去的，加了之后一直没动。

我选它，不是因为它好听。是因为四个字里有动有静，念起来不飘。

这四个字我记了很多年，忘了最初在哪里看到的。后来查过两次，说法不一样，有说写山的，有说写水的，还有说是从前某个人的字号。我不确定，就按自己的理解用：山在那里不动，水从山脚过去。

域名查了三个晚上。shanzhichuanxing.com 太长，念一遍要停两次；mountainriver.com 早就没了；最后注了 mountainandriver.space，首年二十八块。那个 .com 的域名属于一家做建材的公司，首页是一张厂房照片。

网站的样子很简单。左边一栏，三行字：文章、关于、索引。中间是正文，一篇一篇往下排，按年份分组。没有登录，没有评论，没有“热门”。任何人打开都是一样的。

app.py 一共一百四十行。读文件、排顺序、分年份、渲染，各占一段。没有数据库，没有后台，文章就是文件，改一篇就是改一个文件。

周日下午我在配色上花了两个小时。

第一版是墨绿，压在最浅的米色上。`.streamlit/config.toml` 里只有六行，改一个数值，刷新一次页面。墨绿是我想当然的选择，因为书房总得有张绿桌布。

发给阿哲看，他回了一条语音，四秒：“你这个绿太正了，像邮局。”

我改成赭石。改完自己看了十分钟，觉得像一本卖茶叶的宣传册。

又改成灰蓝。这次好一点，但正文压不住，读到第三段眼睛就往外跑。

晚上九点，阿哲打来电话。他在上海，那边也在下雨，能听见他窗户没关严，风一阵一阵的。

“你那个底色偏黄。”他说，“正文别用纯黑，用 #2B2B2B。行高 1.75，字距加一点点。”

“页边距呢？”

“太窄。两千字挤在中间，像在走廊里站着看。”

我一项一项改。改到十点半，页面终于安静下来。底色还是最初那个米色，主色回到墨绿，只是压暗了一点，暗到不那么像邮局。

阿哲最后说了一句：“行了。别再加东西了。”

我答应了。那天晚上没有再加。

第二天下午遇到一个问题。文章按文件名排序，我一开始写的是 2024-10-5，月份和日期都不补零。结果十月五日排在了三月三十一日前面，因为文件名都是 2024- 开头，接下来的字符 1 比 3 小。我把所有文件名检查了一遍，改了十二个。

十一点四十，开始上线。

服务器是前一天买的，一核两G，一年九十九块，在香港的一个机房里。选香港，是因为放在内地的话，域名得先备案。备案要拍照，要填表，要等二十天。我等不了二十天，也懒得去拍那张照片。代价是访问慢一点，从杭州打开要一秒多。

系统装的是 Ubuntu，Python 三点一一。我把代码用 git 推上去，在服务器上拉下来，写了一个 systemd 的服务文件，让它开机自启。

然后装 nginx，把八十端口转到八千五百零一。

证书是用一个免费的工具签的，两条命令，三个月有效，到期自动续。第一次签的时候域名还没解析过来，等了二十分钟。

十一点五十二，我在手机上关掉 Wi-Fi，用流量打开网址。

页面出来了，米色的底，左上角四个字。然后中间开始转圈，转了很久，出来一行小字：Please wait...

我又刷新了一次。还是一样。

电脑上的浏览器是好的。用流量就不行。我把手机连回 Wi-Fi，又好。我坐在那儿想了一会儿，打开电脑的开发者工具，看见一行红字：WebSocket connection failed。

问题不在浏览器，在 nginx。

Streamlit 的页面不是一次发完的，它要在浏览器和服务器之间开一条长连接，一直开着，页面上的东西才动。nginx 默认只转发普通的请求，不管这种升级的连接。请求到了它手里，它转一半，连接就断了。

我在配置文件里加了三行：Upgrade、Connection、还有一个读超时，设成一天。

保存，测试，重载。

十二点二十六分，手机用流量打开，页面停了一秒，四个字出来了，下面的文章列表也出来了。

第一篇的日期是二〇二四年三月三十一日，写的是三月的一场雨。那篇其实早就写好了，一直放在草稿里，等一个地方放。

我在阳台上站着刷新了三次，三次都开。

一点十分，我躺下了，又起来看了一次日志。记录里有一行陌生的 IP，访问了首页，停了两秒，走了。可能是爬虫。我把那一行看了两遍，才关灯。

楼下的运河是黑的，只有对岸一排路灯，光落在水面上，碎成一片一片。

上线第三天，我加了一个阅读数。

一个小方块，在每篇文章的右下角，显示被看过多少次。实现起来不难，页面加载的时候给数据库里的一个数字加一。

加完的第二天，我发现自己一天点开了七次。

那十一天里，我还改过一次配色，把链接的颜色调浅，因为自己点的时候觉得刺眼。

十一天里，我看了四十三次。最多的一天看了九次，其中三次是在地铁上，信号不好，页面没打开，我也点。

第十二天早上，我把它删了。

删的时候要改三处：页面上那一行，后端那个加一的函数，还有数据库里的一张表。表里存着十一天的记录，最多的那篇是二十三，最少的是零。

我把表也删了。删之前看了一眼，那二十三个阅读里，大概有十几个是我自己。

同一个月里还删了别的东西。

索引那一页做过一次。我按关键词做索引，做了半天，最后只有六个词：运河、常山、走路、雨、书、咖啡。六个词不足以索引四十一篇文章，也不足以索引三年。我把它删了，换成一页按年份排的目录。

侧栏本来有一栏叫“最近在读”，接的是我的读书笔记。做了一个月，只更新过两次，后来就一直是那两本书，像一件挂了很久没穿的外套。删掉之后，左边只剩三行字。

“关于”那一页写了五稿。第一稿八百字，从大学写到工作，写完了自己读一遍，像一份简历。第二稿三百字，删掉了年份，读起来又像一段自我介绍。第三稿剩下六行，我盯着看了半天，还是觉得多。

最后定下来的是：

林深，一九九一年生，常山人，住在杭州。

做软件，写点东西。

这里的文章，写一座城、一张书桌、几段山路。

邮箱在下面。

四行。第五行本来想写“欢迎交流”，删了。

邮箱是很多年前注册的那个，前缀里还带着学号。

四月二日，我把网址发给我妈。

她过了半小时才回，说打开了，就是字有点小，看着费劲。

我这才想起来，我是在二十七寸的显示器上排的版，正文十六像素，行高一点七五。在手机上，那个字号勉强，在她那个屏幕更小的手机上，就要眯眼睛。

我改成十七像素，行高一点八。段落之间的距离也加了两像素。

改完再发过去。她说，好多了。

她还说，已经存到微信的收藏里了，以后慢慢看。

过了一会儿，她又发来一条：“你爸问，这个东西别人也能看？”

“能。”

“那要不要钱？”

“服务器一年一百二。”

“哦。”

晚上八点，我爸用我妈的手机发来一条语音，只有五秒。背景里有电视的声音，他在问：“你写的那里面，有没有写我？”

我说没有。

他说：“别写。”

我说好。他那边“嗯”了一声，就把电话给我妈了。

后来我还是写了。写他煮面，写他修东西，写他的手。写的时候不点名，只写“我爸”。他大概不知道，也大概知道。

书房的规矩，是慢慢定下来的。

文件名用日期开头，后面跟一个短标题：2024-03-31-shanzhi.md。所有文章放在 content 下，不分文件夹。草稿放在 drafts，也不分。图片按年份放在 assets 里，文件名不改，因为改了以后就对不上原文。

每篇文章的开头不写日期，日期在文件名里。正文里也不加“文/林深”，因为整个站只有一个人写。

有一条是我后来才想明白的：不给每篇文章单独的网址。

Streamlit 没有路由，所有页面都在一个地址上。点开哪篇，网址都不变。这意味着分享出去永远只能分享首页，也意味着搜索引擎几乎找不到这里。

阿哲说这不行，太不方便。我说就这样。

一间书房，不分成一个个单间。人进来，坐下，看哪本自己抽。

这话我没有说出口，只在心里过了一遍。说出口就有点像标语了。

* * *

二〇二五年十一月，服务器发来续费提醒。

一百二十块，比去年贵了二十一。我打开后台，续了两年。

然后打开网站。首页往下拉，文章一共四十一篇，最新的一篇是十月十九日。再往下，是九月、八月、七月，一页一页，都是这三年里断断续续写下的。

我一直拉到最底下。第一篇的日期是二〇二四年三月三十一日。

点开，读完，退回来。

桌面上那个叫 OLD_500 的硬盘还插着，灯一闪一闪。里面的东西我后来整理了一半，照片按年份分了，文档还是原样。那个叫“1.docx”的文件我没有改名，也没有删。

我打开 drafts 文件夹，找到 2016 那个目录。first-room.md 还在，一年半了，一直没发。

光标在最后一行停了停。

我新建了一个文件，命名 2025-11-16.md，在里面敲了一行日期，保存。

文件是空的，第一行是日期，第二行还没有。

然后合上电脑，去厨房烧一壶水。

等水开了，壶盖响。我站在厨房里等它跳，窗外有辆车开过。
