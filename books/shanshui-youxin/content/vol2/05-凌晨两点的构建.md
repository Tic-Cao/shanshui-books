# 凌晨两点的构建

两点零四分，手机在床头柜上震。先嗡两下，把木头震得响，然后才响铃。

我睡得浅，第一下就醒了，没动。脑子里过了一遍：闹钟？不是。我妈？不会这个点。然后是值班表。这周轮到我。

坐起来摸手机，手背碰到杯子，半杯凉水泼在柜面上，顺着边缘滴到地板。赤脚踩下去，脚底一凉。

屏幕是运维平台推来的，红底白字。

　　[P1] tasks/list p99 2.3s，5xx 3.4%，prod-sh-2，持续 5 分钟

底下还有一行小字：零点五十二起错误日志上升。

我把这条读了两遍。2.3 秒，3.4%，数字不算大。凌晨的脑子像一台刚开机的旧机器，风扇先转，屏幕还没亮。

我把杯子扶起来，用 T 恤下摆擦了擦柜面。擦到一半停住，觉得这个动作很多余。

光脚走到书架前，把工作用的笔记本从词典底下抽出来。词典是《现代汉语词典》，第六版，压在电脑上，是因为那一格太浅，电脑立不住。

开机，风扇响。输密码，第一次输错。手指是凉的，也因为 6 和 7 挨得太近。

VPN 令牌在手机里，六位数，三十秒换一次。我输进去的时候，数字刚跳。

连上，打开监控。

全站的错误率是 0.31%，一条平线，绿色。请求量在凌晨掉下去，像退潮。只有一张图不一样：按集群拆开，prod-sh-2 那条线从零点五十二分起抬了头，停在 3% 到 4% 之间。

告警是按全站错误率配的，阈值 1%。这个集群只占全部流量的百分之四。出多大的事，摊到全站都不够 1%。

这条规则是上个月改的。之前按集群配，一天响十几次，有一次凌晨响了四遍，起来一看是爬虫。大家都烦，运维就说合并成一条，按全站算。

合并那天在群里发过截图，没有人反对。我也点了赞。

我盯着那条线，才明白它已经抬了一个多小时。

日志系统里，同一个报错刷了八千多条。

　　TypeError: Cannot read properties of undefined (reading 'level')
　　at getFieldPermission (permissions.js:88:31)

八十八行是上周写的。字段权限，合同金额、供应商报价、成本单价三个字段，按角色分只读和可编辑。客户催了半年，这个版本终于上了。

版本号 2.9.0，晚上十一点四十发的。那天办公室只剩我和小唐，他九点多先走，走之前把发布单又过了一遍，问我第十一项填了没有。

发布单十四项。第十一项是：缓存 key 是否带版本。

我勾了。

先是两个 pod 的灰度，看十分钟，然后按租户放到百分之五。零点四十扩的。

零点二十，我关电脑回家。扩量的定时任务在零点四十，我没等。以前也没等过，灰度没出过事。

那十分钟里，监控是绿的。现在想起来，那十分钟只有三次请求，全是运维的探针，每次都是新登录，缓存是空的。真正的人一个都没进来。

代码不长。从缓存里取这个人的权限，取到之后看字段上的 level。

缓存是去年小唐加的。key 是 perm 加租户加用户，二十四小时过期。没有版本号。

新的权限对象长这样：{ level: 'read' }。旧的是一个 true。

新的读旧的，读到 undefined，报错。

那旧的读新的呢。

这个念头到两点半才真正落下来。当时我没顾上，脑子里只有一句话：先回滚。

但在回滚之前，我干了一件蠢事。

我重启了服务。

这是本能。以前遇到说不清的报错，重启能解决一半。手指比脑子快，命令敲下去，八个 pod 一个个退出，又一个个起来。

起来之后错误没停，反而多了。缓存空了，所有人都去数据库取权限，数据库的 CPU 从百分之二十冲到八十九。p99 变成五秒。

我想找回滚手册，在 wiki 里搜了两次没搜到，最后是从浏览器历史里翻出来的。上次打开是去年八月。

手机在桌上震，是语音。老周。

四十七秒。他那边有抽油烟机的声音，或者加湿器。

“我看到告警了。你先回滚，别查了。回滚完在群里说一声。要人我过来。”

停了两秒，他又说：“别一个人扛。”

我回了一个“好”。

那条语音我又听了一遍。第二遍才听出来，是加湿器，一两秒冒一下的那种咕噜声。他大概也是刚醒。

两点二十二，开始回滚。

回滚不是把镜像换回去，是把三个星期前的那个 commit 重新构建一遍。构建号 2319，日志一行一行往上走，和十一点四十那次的 2317 长得一模一样：拉代码、装依赖、跑测试、打镜像、推仓库。

四百一十二个测试，全部通过。

五分二十秒，构建成功。绿色的勾。

我点了部署。pod 的状态从 Terminating 变成 Running，一个个变绿。那四分钟我什么也没干，就看着。

两点三十一，错误率从 3.4% 掉到 0.2%。

又过了两分钟，0.05%。

我靠在椅背上，听见耳朵里有很细的鸣声，像很远的地方有一只蝉。

然后我想起旧代码里的那个判断。

我把 2.8.3 的代码拉下来，打开同一个文件。旧版本只有十二行，没有 level，只有一个布尔值。

　　if (perm[fieldId]) { canEdit = true }

一个对象，只要不是 null，就是 true。

我打开缓存，随手取了一个 key。{ level: "read" }。

手心开始出汗。

两点三十三，给老周发消息：回滚了。但缓存里是新结构，老代码会把对象当成 true。要清。

他直接打电话过来。四十秒。

“清。分批。看着数据库。”

“好。”

“清完睡觉。”

我用了 SCAN，没用 KEYS。四千一百八十六个 key，一次两百，UNLINK，停三十秒，看数据库的 CPU。从百分之二十二慢慢升到五十八，停住。

两点四十七，清完。

错误率是 0.00%。

0.00% 不代表对了。它只代表没有人再报错。

我把监控的时间范围拉到两个小时，又拉回十分钟。那条线平了，平得让人不放心。

运维在群里回了一句：数据库稳住了。

我在事故群里发了一句：缓存已清，权限按数据库重算。要查审计日志。

小唐是两点三十一上线的。

他发来一句“我还没睡”，后面跟着“正在输入”，点了很久，发过来的是：“缓存是不是没分版本。”

我已经知道了。可看到他这句话，还是坐了一会儿。

我说，是。回滚了，缓存也清了。

他说，我改 key，加个 v2。

我说，明天。

他说，我现在改，改完睡。

三点零六，他推了一个 commit。key 里加了版本，读不到就回源，写的时候带 TTL。commit message 只有四个字：加个版本。

我没回。我在写时间线。时间线写到两点四十七，后面空了一段。那十九分钟我在看缓存，什么也没写。

审计日志的查询语句我改了三遍。字段权限的修改会记一条，动作是 field_update，对象是 contract_amount 和 supplier_quote。

时间范围：零点四十到两点四十七。

出来六条。三个用户，两个租户。

一条是把合同金额从八十六万改成九十二万。一条是把供应商报价的小数点挪了一位，从 12800 改成 1280，四分钟后又改回去。

还有四条是备注字段，不重要，但也在里面。

我把六条导成 CSV，存在桌面上，文件名带了日期。

三点四十，小唐发来一句：那六条怎么办。

我说，明天老周处理。

他说，要不要现在给客户发个邮件。

我说，半夜发，人家以为出多大事。

他隔了一会儿回：本来就不是小事。

我盯着这句话，没找到可以回的字。最后打了一个“睡吧”，发出去，觉得轻了，又补了一句“明天我写说明”。

他回了一个“好”。

然后我开始写事故说明。

模板有五栏：影响、时间线、原因、处置、改进。

影响那一栏我写了很久。三十七个租户在灰度里。其中两个租户的三名用户，在回滚后的十六分钟里，改了六个本来没有权限改的字段。一个客户的导出任务在零点五十二到两点二十六之间失败了十四次。

发现耗时：七十二分钟。

我盯着这个数字。从第一个错误日志到我知道，七十二分钟。中间隔着一个后半夜，隔着全站 0.31% 的平均值，隔着一条按比例配的告警线。

改进项写了五条。缓存 key 带版本，已经做了。告警按集群和租户拆，阈值改成错误数，运维周三前。发布窗口从午夜挪到周二上午十点。检查项第十一条从“勾选”改成“贴命令输出”。回滚手册加一条：回滚后清缓存。

写第十一条的时候，我停下来查了发布记录。那个框是我勾的，晚上十一点十分。

我想在文档里写一句“勾选不等于检查”，敲出来，看了一遍，删了。太像一句标语。最后写的是：发布时该项已勾选。

四点五十，老周打电话来。两分钟。

“清完了？”

“清完了。”

“小唐改的 key 你看了？”

“看了。读不到回源，写的时候带 TTL。”

“他一个人弄到三点多？”

“嗯。”

“让他睡。你也睡。”

我嗯了一声。他停了一下，又说：“周二上午十点发不了，客户在用。”说的是我把发布窗口改到上午那一条。他把那条改成了“发布前与客户确认窗口”。

我说好。

五点二十，运维在文档里回了一句：告警拆分今天做，阈值按错误数，先跑一周看看。

我在下面回：好。

五点多，走廊的灯自己亮了。清洁的阿姨推着车进来，看见我，愣了一下。

“又通宵啊。”

“嗯。”

她把垃圾桶里的外卖盒收走，拖把在我椅子旁边绕了一圈。我把脚抬起来，又放下。

“年轻人，莫熬夜。”

“晓得了。”

她走了以后，办公室又安静下来。中央空调没开，只有机房那边的风扇声，隔着两道门，一直响。

我打开值班表。下下周又是我，二十五号。排班的时候小唐问过我那天有没有事，我说没有。

六点，我打开构建页面。2317 和 2319 并排在那里，两个绿色的勾。2317 是发布，2319 是撤回。同一个 commit 的上一版，三个小时里构建了两次。

我点进 2317 的日志，翻到最后。“All 412 tests passed.” 时间戳是二十三点四十六分五十八秒。

又回到发布页。十四项，十四个绿勾。第十一项“缓存 key 是否带版本”，后面写着我的名字，二十三点十分。

四百一十二个测试，没有一个用过旧结构的缓存。

我关了页面，收电脑。背包的拉链卡住，拉了两下才过去。

出楼的时候，保安在椅子上打盹，头一点一点的。门禁的屏幕亮着，我刷了工牌，它“滴”一声，显示：06:09，今日 6 小时 29 分。

玻璃门推开，外面的天是深蓝的，路灯还亮着，路面有一点湿，不知道是洒水车还是露水。一个骑电瓶车的人从面前过去，车把上挂着挡风的棉被，蓝色的，边角磨白了。

我沿着温州路走。环卫工在扫落叶，扫帚擦过地面，一声一声。早餐摊已经支起来了，蒸笼摞得很高，白气从缝里往外冒。

男人在案板前包馄饨，手指很快，捏一下，丢一个，案板上撒着薄薄一层面粉。女人守着锅，袖套是蓝的，指节粗，指甲剪得很短。

我要了一碗小馄饨，六块。她一边下一边问：“上班这么早？”

“下班。”

她笑了一下，多抓了一小把虾皮撒进去。

我坐在折叠桌边上等。汤很烫，我先没动。旁边桌坐着一个穿保安服的男人，吃拌面，手机靠在醋瓶上看视频，声音开得很小。醋瓶的盖子缺了一角。

天从深蓝变成灰，再变成一点白。对面的写字楼有一层亮了灯，只有一格。

馄饨吃完，汤剩了一半。我起身的时候，腿有点麻。

回去的路上绕了一段运河。河面上有雾，一条货船从桥下过，船尾的水翻起来，又慢慢平下去。岸边有人在打太极，录音机放在石凳上，声音很小。

走到小区门口，手机震了一下。工单系统。

标题是：导出任务连续失败。

正文很短：我们昨天晚上九点导出的进度表，到今天早上还是失败的。今天上午九点有个验收，要用这份表。另外昨晚的提醒也没收到。

落款是一个我没见过的名字，做建筑劳务的那家客户。

我站在门禁前面，把这条读了两遍。昨晚九点，我还在办公室看发布单。那时候一切正常。

我转发给老周，写了三个字：刚看到。

他回：我来回。你睡觉。

* * *

到家是六点五十。洗澡的时候，热水冲在后颈上，我才觉得后背是僵的。躺下就睡着了。

醒来是下午四点半。屋里很暗，窗帘拉着，嘴里发干，舌头上像贴了一层纸。手机在枕头边，屏幕一亮，七条消息。

老周九点零五分发的那条：今天你别管了，上午的会我开了，四个电话我打。

十一点二十：两个要书面说明，一个要下周去现场。你睡醒再说。

十三点四十：做劳务那家的验收改到四号了。他们项目经理没说什么，就问了一句，你们的提醒是不是经常这样。

我没回这条。把手机扣在枕头上，又躺了十分钟。天花板有一道细缝，从灯座一直裂到窗边，我以前没注意过。

小满五点多发了两条：我们先搬了。给你留了一本，放柜台。

我坐起来，头发压得一边高一边低。给她回：对不起，我睡过去了。现在过来。

她回得很快：来吧，门还开着。

我洗了个澡，刮了胡子，出门已经七点十分。楼下陈阿姨在收衣服，看见我，问这两天怎么没见人。我说加班。她哦了一声，说夜里凉了，阳台的窗记得关。

小河直街在运河边上，离我住的地方走路二十分钟。我到的时候七点半，天已经黑了，沿街的灯笼亮着，游客不多，有人蹲在桥边拍照。

书店的卷帘门拉下来一半。小满在里面拖地，头发扎起来，围裙上有一道灰。店里有一股新书和湿拖把混在一起的味道。

四十箱书，她说，搬了一下午，你这时候来，正好赶上拖地。

我说我来。

她说你脸色像纸，坐着。

我还是去搬了。角落还剩两箱，一箱诗集，一箱画册。我蹲下去，手扣住纸箱的底，起了一下，腰上使不上劲，箱子只离地两寸。手上立刻沾了一层灰。

小满走过来，把拖把靠在架上。

“放着。”

她把箱子抱起来，膝盖一顶，送到架子上。她比我矮半个头。

柜台上有一个牛皮纸包，压着一张便签，上面写：给林深。我打开，是一本旧书，布面精装，书脊上印着《河与桥》，纸已经发黄，扉页有一个蓝墨水的签名，认不出是谁。签名下面还有一行小字：一九八六年春，于拱宸桥。

便签背面还有一行：上次你说想找的，我收书的时候碰上了。三十五块，不用给。

我翻了两页，没读进去。字是竖排的，纸很脆。

我把五十块压在收银台的镇纸底下。

她看见了，没说话，继续拖地。

水管下午漏了，她说，修到五点多，所以今天什么都是乱的。

我说我那边也是。

她没问是什么事。拖把拧干，靠回桶边，水顺着布条往下滴。

今天不请你吃饭了，她说，改天。

我站在门口，替她扶着门。门是旧的，带弹簧，松开就自己回来。她用推车把剩下的书推进里间，轮子压过门槛，咯噔一下。

我用膝盖顶住门，等她过去。
